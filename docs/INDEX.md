# Kazalo radne dokumentacije

Ova dokumentacija služi organizaciji projekta. Ne predstavlja tekst seminara.

| Dokument | Svrha |
| --- | --- |
| [AGENTS.md](../AGENTS.md) | Pravila za cijeli repo i granica dopuštene uporabe AI-ja. |
| [Pravila kolegija](PRAVILA_KOLEGIJA.md) | Zahtjevi koje je autor dostavio. |
| [Protokol izmjena](PROTOKOL_IZMJENA.md) | Tijek samostalnog rada i povezane izmjene. |
| [Plan seminara](plan/SEMINAR.md) | Opseg, otvorene odluke, koraci i završna provjera. |
| [Izvori](IZVORI.md) | Evidencija kandidata, provjere i korištenih materijala. |
| [Uporaba AI-ja](AI_UPORABA.md) | Stvarno korišteni alati i njihove namjene. |
| [Radna skripta](skripta/skripta.tex) | Skripta za autorovo učenje teorije (uz AI pomoć) i zajednička bibliografija `skripta/literatura.bib`; nije tekst za predaju. |

Izvornike uputa kolegija i dopuštene lokalne materijale po potrebi dodaj u
`docs/materijali/`. Čuvaj izvorni sadržaj i zabilježi odakle je preuzet.
